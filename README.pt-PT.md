# PurePass

**Demo:** [joaomrb.github.io/PurePass](https://joaomrb.github.io/PurePass/) · **Repositório:** [github.com/JoaoMRB/PurePass](https://github.com/JoaoMRB/PurePass)

🌐 **Ler em:** [**English**](./README.md)

---

Gerador de palavras-passe e passphrases com design premium, geração reativa e 100% local.

## Funcionalidades

-  Geração criptográfica via Web Crypto API
-  Atualização instantânea ao alterar opções
-  Interface bilingue PT / EN
-  5 temas de cor + modo claro/escuro
-  Limpeza automática do clipboard (30s)
-  Modo passphrase estilo Diceware
-  Análise de entropia e tempo de quebra
-  Presets: Legível, Blindada, PIN

## Stack

- **React 19** + **TypeScript** + **Vite**
- **Lucide React** (ícones)
- Zero backend — tudo corre no browser

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
